# ADR 0001: モジュラーモノリスとLocal-firstを採用する

- 状態: 採用
- 日付: 2026-07-18

## 背景

筋トレ日記は個人向けのオフラインPWAであり、通信不能時にも記録できることが主要価値である。一方、画面がDexieへ直接依存していたため、クラウド同期を追加すると全画面へ変更が波及する状態だった。

## 決定

機能別モジュラーモノリス、軽量なClean Architecture、IndexedDBを一次保存先とするLocal-firstを採用する。UIはApplication Use Caseを呼び、Repository PortのDexie実装はInfrastructureへ置く。

現在の規模では運用コストが効果を上回るため、マイクロサービス、Event Sourcing、全面的CQRSを採用しない。バックアップv1は競合解決を必要としない置換復元だけを提供する。認証とクラウド同期は、削除・競合・ログアウト時のデータ保持方針を決めてから独立して実装する。
